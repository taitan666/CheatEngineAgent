# Gate 4a 单机游戏只读验收记录模板

仅用于玩家当次明确授权的单机离线进程。记录元数据，不记录 API 密钥、完整个人路径、存档正文或固定运行时地址；地址不能当作跨次配方。任何写入均不属于本验收。

| 字段 | 本次记录 |
| --- | --- |
| 验收时间与操作者 | 未执行 |
| 游戏与 `game_version` | 未执行 |
| `process_identity`：PID、启动时间、EXE 哈希、Epoch | 未执行 |
| `scan_scope`：区域类别、范围摘要、上限、授权确认 | 未执行 |
| `value_type`、字节序、对齐 | 未执行 |
| `coverage`：请求/已检查/跳过字节，complete、partial_reason | 未执行 |
| `operator_observed_values`：三次人工可见数值 | 未执行 |
| `initial_count` 与两次 `refine_counts` | 未执行 |
| `readback_result`：候选只读复核及匹配时间 | 未执行 |
| 取消/重附加后旧 Epoch 拒绝证据 | 未执行 |
| 结论：已验证/不确定/失败及原因 | 未执行 |

若范围未覆盖目标页、候选不唯一、类型不明确、任一步为 partial，或游戏版本/身份发生变化，结论必须为“不确定”；不得写成“整个进程未找到”或“已找到信用点”。

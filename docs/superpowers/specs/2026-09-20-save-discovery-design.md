# 存档导入与按需发现设计

日期：2026-09-20  
状态：用户已确认，分阶段实施中  
依赖：`2026-09-19-game-companion-save-architecture.md`

## 意图与决定

让玩家容易找到自己有权使用的单机离线存档，同时避免 AI 或后台进程在未经同意时遍历私人文件。采用“玩家导入为主、按需辅助发现”：现有单文件选择保留；新增授权目录与常见位置建议。无启动时扫描、无全盘扫描、无模型直接文件系统权限。发现候选不等于授权读取，更不等于授权写入。

纯手动选择无需新权限，但难找的游戏目录体验差；自动全盘搜索虽方便，却扩大隐私、性能和误识别风险。混合方案只在玩家主动点击后搜索明示范围，作为本期唯一方案。

## 权限与数据流

1. UI 提供“选择存档文件”“授权一个目录”“查找常见位置”三个入口。选择文件沿用现有本机确认。目录入口显示规范化根路径、预计扫描范围和取消按钮，玩家确认后才建立一次会话内的 `DiscoveryScope`。
2. “常见位置”只列出通过 Windows Known Folder 等受支持机制解析出的候选根目录，并逐项请玩家勾选；不能默默搜索所有用户目录、所有盘符、Steam 库、云盘或网络共享。具体游戏路径规则作为带版本的可审阅提示，不成为授权来源。
3. `SaveDiscoveryService` 调用只读 Windows 枚举端口，受根目录、深度、文件数、时间及取消预算约束。目录重解析点、符号链接、网络路径和跳出作用域的子路径拒绝跟随；不可访问、过大或云占位项仅报告原因，不自动提升权限、下载云内容或打开正文。
4. 枚举阶段只收集必要的名称、扩展名、长度、修改时间及路径来源；不读取存档内容，不计算内容哈希，不执行脚本。候选路径只在本机 UI 显示，日志和 MCP 不返回不必要的绝对路径。
5. `SaveCandidate` 显示可能的游戏/槽位与匹配依据，注明“推测”或“未知”，不由 AI 断定真实性。玩家点选具体文件并确认授权、单机离线用途后，才调用现有 `InspectSaveFile` 进行句柄身份、SHA-256、64 MiB 上限和格式探测。文件变化时重新选择或检查，不沿用旧候选的权限。
6. AI 只能对已生成的脱敏候选摘要排序或解释，不能发起扩大范围、读取文件正文、备份、编辑或恢复的调用。MCP 最多查询本机已授权会话的脱敏候选投影；不提供任意路径参数和新建扫描作用域的工具。

## 契约与状态

`DiscoveryScope` 保存会话 ID、创建方式、规范化根目录引用、授权时间、预算和撤销状态。默认仅本次应用会话有效；“记住这个目录”若将来加入，须单独征得同意并有可见的撤销入口。`SaveCandidate` 保存候选 ID、作用域 ID、来源规则版本、相对路径显示名、元数据、置信等级和观察时间；不是 `SaveTarget`、`SaveSnapshot` 或 Effect。

撤销范围立即停止枚举、清除候选和当前选择，并阻止基于该范围新建的存档 Effect。撤销不删除原件或已产生的备份；已经在执行的 Effect 按 AgentOS 的真实结果记账，不能假称未发生。重新授权必须重新取得候选和文件身份。无授权的本机选择不得通过 MCP 补授。

## UI 与错误语义

存档工作台将“发现候选”和“已选择/已核验的存档”分区展示。列表必须显示来源、匹配依据、是否云同步/占用或未知、候选是否过期；“检查文件”是明确的下一步。备份、编辑和恢复按钮继续由现有快照、格式、Proof 与本机审批门禁控制，不能因候选排名而启用。

扫描达到预算、访问被拒、取消、云占位、目录变化或规则冲突时，展示部分结果及明确原因，不以“未找到存档”掩盖不完整扫描。后台任务不阻塞 Lazarus UI；关闭窗口或撤销范围停止任务。未知游戏和未知格式可被选择进入只读检查，但写能力仍由经过验证的格式 Codec 决定。

## 安全与验收

- 启动、LLM 请求和 MCP 请求均不会自动扫描文件系统；仅本机玩家操作能建立发现范围。
- 未勾选的常见位置、作用域外路径、重解析目录、网络共享和云占位项不会被遍历或自动下载。
- 枚举预算和取消生效；超限报告覆盖缺口，候选不含正文、密钥或完整文件字节。
- 同名不同槽位/版本分别展示；文件被移动或改写后旧候选不能绕开 `InspectSaveFile` 的身份与哈希复核。
- 撤销范围会阻止新发现和新 Effect；现有执行状态、Receipt/Proof 和备份不被静默删除。
- UI 可用键盘完成授权、取消、选择及检查；真实游戏目录布局测试需玩家提供授权样本，测试规则不能宣称覆盖所有游戏。

本设计不解决现有按路径替换的原子身份比较风险。按 `docs/delivery/verification-report.md`，真实存档写入和发布验收仍为阻断项；目录发现完成也不会自动提升 Gate 9。

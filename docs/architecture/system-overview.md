# System overview

The current authority is the [2026-09-13 Game Companion baseline](../superpowers/specs/2026-09-13-game-companion-rebaseline.md), amended by [ADR 0005](../decisions/0005-standalone-lazarus-host.md).

CheatEngineAgent is the repository name for Game Companion Console, a Windows-first standalone Lazarus/Free Pascal AI game assistant. The product core is the player-facing Game Companion workflow: understand the current game and progress, map observations into semantic state, surface contextual help and secondary-screen views, preserve meaningful events, and optionally assist with verified modifications. Platform-neutral candidate discovery, evidence and verification are supporting technical services—not the product identity. The application's local state, authorization, durable execution and proof services remain the sole owners of canonical state and completion.

The primary first-stage user surface is its own native Lazarus/Delphi AI workbench. MCP is a secondary loopback control and diagnostic adapter. Win32 process access, CT knowledge, LLM, persistence, UI and future Android support remain replaceable adapters around the shared domain and governance contracts. Upstream Cheat Engine is a reference source, not the application host.

The intended player-facing flow is game selection → bounded state sampling from authorized sources → semantic Game State Model → secondary-screen and contextual assistance → event/evidence capture → optional locally approved modification → readback verification → reusable Game Profile. Internally, some discovery steps use Experiment/Candidate/Hypothesis records. Failures, inconclusive checks and unknown outcomes are recorded rather than converted to success.

Current implementation is partial: the standalone executable, state-store and governance foundations, loopback MCP HTTP, real Win32 process access, bounded AOB scanning, minimal disassembly, locally approved compare-write-readback effects, bounded freeze sessions, durable Approval/Receipt/Proof evidence, emergency stop, Credential Manager-backed OpenAI-compatible and Anthropic-compatible calls, and local CT XML-to-SQLite RAG with fuzzy retrieval exist. Freeze sessions bind an exact target/address/value pair, stop on a third value, write-count budget or expiry, and never auto-resume or auto-restore. Model calls apply prompt/RAG/output byte and token budgets before credential access, surface actual provider token usage, do not retry timeout or cancellation, and run outside the UI thread with cancellation and thread-safe SSE delta display. The approved lightweight CT retrieval supports a bounded common-cheat pinyin vocabulary and deterministic token-set ranking, not general neural embeddings. Live third-party-provider interoperability, the complete native AI workbench acceptance and Android host remain incomplete.
